# Языковые модели в работе преподавателя медицинского вуза

Интерактивная версия открытого учебного пособия (редакция 2026 года).

- **17 модулей** с оглавлением, прогрессом чтения и сносками на источники
- **354 промпта**: банк из 100 шаблонов и примеры из модулей, копирование в одно касание, избранное
- **Глоссарий** из 41 термина со словарём и режимом карточек
- **13 тестов** для самопроверки по модулям 1–13
- **Поиск** с учётом форм русских слов и подсветкой найденного
- **30 источников**, проверенных 26.10.2026

Приложение состоит из одного файла `index.html` и работает без сервера и сборки. Прогресс чтения, избранное и результаты тестов хранятся в браузере читателя.

## Как открыть

Опубликованная версия: GitHub Pages этого репозитория (Settings → Pages).
Локально: скачайте `index.html` и откройте в браузере.
